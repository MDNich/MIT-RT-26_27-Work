# Iris handover and physical interference tests

Use the existing study environment and pinned Java 17 OpenRocket JAR. From the study root, after the earlier blend has built its classes and replay inputs, run `./followup/run-engine.sh`, `./followup/run-loads.sh`, `python3 followup/analyze.py`, `python3 followup/diagnostics.py` and `python3 followup/figures.py`. The top-level reproduction driver runs these in order. Outputs live in `results/followup` and `figures/handover-*.pdf`. The separately named flight history is `results/handover-preferred-candidate.csv.gz`. The report contains the quantitative decision.

* `protocol.md` fixes the handover and NACA split. `build.py` builds the candidate as a separate Java class overlay. The JAR and deployed option are pinned to the baseline described in the root README.
* `Loads.java` constructs literal CDX1 and original ORK fixture sweeps at 0/2/4 deg, plus the tunnel body, full-span isolated wing and body-clipped wing. The forebody CDX1 uses a 4.02-in maximum diameter. The other two CDX1s and all reported Iris loads use a common 4.20-in diameter after normalization. For an independent check on equivalent camera area, see the two additional native exports in `inputs/iris-components/no-protuberance/`.
* `tn3795.csv` transcribes NACA's printed Tables I–II; see `inputs/tn3795` for scans and source. The reserved ranks are W2/W4/W6. The centerline wing apex is 8 inches minus the tabulated root chord; the complete delta has zero tip chord and its centroid is one-third root chord forward of its trailing edge. The wing-only fixture uses two opposing fins on a 0.00001-in-radius carrier. The assembly uses a 1.50-in diameter body with 3-in exposed root chord. The wind-tunnel balance and sting are omitted. OR models a uniform thickness and rounded section; the actual wings had streamwise double-wedge sections. A 24-frustum circular fairing follows the cone. The 11-in length Reynolds number is set to 5.5 million at each Mach. Doubling the fairing resolution and halving the carrier radius changes predicted CP by at most 0.00053 in; see `refined-loads.csv`. The body reference moment is about its nose. Wing/assembly native moments are about the full planform centroid. The derived interference moment uses a common **lift-based** nose convention; an exact body-axis translation would also require the experimental zero-incidence drag.
* `states.csv` and `increments.csv` store effective normal-force slope N and normalized first moment J (positive aft). At finite incidence multiply by alpha in radians for CN; multiply J by negative alpha for nose-down pitching-moment coefficient. `attribution.csv` contains the exact additive decomposition at the exported 2 and 4 degrees. `zero-attribution-sensitivity.csv` labels the force-slope assumption at 0 degrees; `slope-proxy-flight-check.csv` compares its aggregate behavior on the real RASAero trajectory.
* `join-check.csv` checks force/moment continuity using one-sided second-order differences. `regression.csv` and `earlier-tunnels.csv` preserve the prior test cohorts. `tn-native.csv` reports force and native-reference moment before converting to effective lift-center positions. `tn-interference.csv` subtracts isolated body and complete wing. `flight.csv` contains minima, burnout and margin RMSE using native flight timestamps.
