# Rocket GNC Monitor reports

- **[Station network requirements and protocol](station-network/Ground_Station_Network_Requirements_Protocol.pdf)** — proposed ten-computer discovery, telemetry/status and H.264/SRT video protocol, with requirements and acceptance tests. Design specification, not implemented-feature documentation. [LaTeX and examples](station-network/README.md).
- **[v0a / 0.1.1 manual](v0a/Rocket_GNC_Monitor_v0a.pdf)** — current released baseline: operator functionality, station/video roles, developer architecture, protocols, persistence, native packaging and validation. [LaTeX source and rebuild instructions](v0a/README.md).
- **[v0 manual](v0/Rocket_GNC_Monitor_v0.pdf)** — historical September 2026 report, retained unchanged.

The maintained application now lives in [MIT-Rocket-Team/RT_Telemetry_UI](https://github.com/MIT-Rocket-Team/RT_Telemetry_UI). These reports stay in the parent project repository. The v0a report is pinned to the published **v0.1.1** source, independently of later in-progress application changes.
