\section*{Document control and reading guide}
\addcontentsline{toc}{section}{Document control and reading guide}
This report documents the released \textbf{Rocket GNC Monitor v0a, version
0.1.1}. Part I describes operation at the Launch station and four Away
stations. Part II describes the implementation, wire contracts, storage,
graphics, extension points and native build process. The appendices contain
complete mission, normalized sample and legacy CSV field references.

\subsection*{What changed since v0}
Station workspaces replace the tab-centered layout: Launch Telemetry spans
Flight and Systems, Away Telemetry uses one window, and Video has its own role.
The wizard adds numbered stations, optional remembered setup and URRG presets.
Iris receiver assignments distribute three system video channels across Away
stations. The new rocket graphic distinguishes raw gyro integrals from genuine
orientation. The migrated application now has verified Mac universal and
Windows x64 packages; physical equipment acceptance remains separate.
