\section{Example exchanges}
These complete JSON files illustrate the normative field names. UUIDs, addresses,
tokens and measurements are synthetic. \code{raw_b64} in the observation example
encodes a documentation fixture, not a valid Zephyrus packet; its digest is real
for those fixture bytes. The example decoder and native schema names are not
claims about production firmware. Token values must be generated at runtime.
